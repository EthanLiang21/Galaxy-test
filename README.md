# Galaxy test — 太阳系 3D 交互模拟 V6

单文件 HTML（Three.js WebGL）实现的太阳系交互演示，无需构建、无需 npm 安装。直接用浏览器打开 `index.html` 即可运行。本地只保留 V6 一份文件（v4 / v5 / v6 的更新内容合并记录）。

**[在线演示（GitHub Pages）](https://ethanliang21.github.io/Galaxy-test/)** · **[版本记录](UPDATE-HISTORY.md)**

## 功能

- **真实轨道力学**：八大行星 + 冥王星、谷神星按 J2000 平均轨道根数 + 开普勒方程数值解实时定位；椭圆轨道、近日点加速、轨道倾角均按真实数据呈现
- **真实时间比例**：公转、自转、卫星轨道均采用真实周期；流速滑杆从**实时（1 秒/秒）**到 4000 天/秒，含实时 / 1 分 / 1 时 / 1 天 / 1 月 / 1 年每秒快捷档——可慢放观察人造卫星
- **四颗真实彗星**：1P/哈雷（逆行 75.3 年）、2P/恩克（3.3 年）、67P（罗塞塔目标）、109P/斯威夫特-塔特尔（英仙雨母体）；独立彗核贴图、彗发、背向太阳的尘埃尾 + 离子尾（随日心距伸缩）、虚线轨道与轨道标注、可点击资料
- **日月食阴影**：月球本影/半影扫过地球向阳面，含“日食演示”自动搜索并定格食甚；另有月食红月
- **完整天体系统**：月球（潮汐锁定）、木星伽利略卫星 4 颗、土卫二/土卫六、国际空间站/中国空间站/哈勃/北斗三号（静止轨道，模型含桁架、帆板网格、舱段、天线等细节）、小行星带、奥尔特云
- **土星环细节**：卡西尼探测器影像配色（C 环 / B 环 / 卡西尼缝 / A 环 / 恩克缝）+ 自定义着色器实现行星投在环上的真实阴影
- **着色器建模**：太阳 fbm 米粒组织动画 + 临边昏暗 + 色球针状体 + 日冕散射壳；行星大气菲涅尔边缘光；Bloom 辉光（高清 / 极致档）
- **真实贴图**：行星表面来自 NASA/JPL 公开影像；银河背景来自 ESO/S. Brunier 银河全景（CC BY 4.0，SD→HD 8MB→4K 备源三级加载）；离线时自动回退程序化纹理
- **视角与操控**：8 组预设视角（含 🛰 卫星特写）+ 9 颗行星独立视角（折叠面板）；WASD 自由飞行（V 键，移动端摇杆）；鼠标拖拽/滚轮缩放；画质三档（流畅 / 高清 / 极致）
- **银河系模式**：太阳携带八大行星与奥尔特云以约 230 km/s 绕银心公转（约 2.3 亿年/银河年）；太阳位于距银心约 2.6 万光年处（猎户臂），黄道面相对银道面倾斜 60.2°，附太阳轨道参考圈与标注

## 使用

直接用浏览器打开 `index.html`，或部署到任意静态服务器。首次加载需联网获取 Three.js、行星贴图与银河背景（均来自公开 CDN）；断网时自动回退程序化纹理。

快捷键：`V` 自由飞行 / `P` 暂停 / `空格` 暂停或（飞行时）上升。移动端：底部三 tab（视角 / 详情 / 控制）抽屉收纳。

## 比例与精度说明

- 行星半径按立方根比例（相对大小基本保真）；轨道距离按幂律 `36·a^0.68` 压缩；月球距离约 15 个地球半径（真实 60）；GEO 卫星按真实 6.6 R⊕；太阳半径未按比例（真实约需 65 单位）——ⓘ 按钮有完整基准说明
- 日食/月食阴影大小经视觉放大以便观察；彗尾长度/亮度为示意（随日心距变化）
- 冥王星、谷神星及四颗彗星轨道根数为近似值；月球相位未做精确对齐
- 银河系模型为形态示意，太阳系与奥尔特云尺寸极度放大才能在此尺度可见
