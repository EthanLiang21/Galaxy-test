# Galaxy test — 太阳系 3D 交互模拟

单文件 HTML（Three.js WebGL）实现的太阳系交互演示，无需构建、无需 npm 安装。直接用浏览器打开 `index.html` 即可运行。

**[在线演示（GitHub Pages）](https://ethanliang21.github.io/Galaxy-test/)** · **[版本记录](UPDATE-HISTORY.md)**

## 功能

- **真实轨道力学**：八大行星 + 冥王星、谷神星按 J2000 平均轨道根数 + 开普勒方程数值解实时定位；椭圆轨道、近日点加速、轨道倾角均按真实数据呈现
- **真实时间比例**：公转、自转、卫星轨道均采用真实周期；可选“放慢自转”演示开关
- **日月食阴影**：月球本影/半影扫过地球向阳面，含“日食演示”自动搜索并定格食甚；另有月食红月
- **完整天体系统**：月球（潮汐锁定）、木星伽利略卫星 4 颗、土卫二/土卫六、国际空间站/中国空间站/哈勃/北斗三号（静止轨道）、小行星带、奥尔特云
- **土星环细节**：卡西尼探测器影像配色（C 环 / B 环 / 卡西尼缝 / A 环 / 恩克缝）
- **真实贴图**：行星表面来自 NASA/JPL 公开影像；银河背景来自 ESO/S. Brunier 银河全景（CC BY 4.0）；离线时自动回退程序化纹理
- **视角与操控**：7 组预设视角 + 9 颗行星独立视角（折叠面板）；WASD 自由飞行（V 键，移动端摇杆）；鼠标拖拽/滚轮缩放；画质三档（流畅 / 高清 / 极致，极致档含 Bloom 辉光）
- **银河系模式**：简化模型演示太阳携带八大行星与奥尔特云绕银心公转（约 2.25 亿年/银河年）

## 使用

直接用浏览器打开 `index.html`，或部署到任意静态服务器。首次加载需联网获取 Three.js、行星贴图与银河背景（均来自公开 CDN）；断网时自动回退程序化纹理。

快捷键：`V` 自由飞行 / `P` 暂停 / `空格` 暂停或（飞行时）上升。

## 比例与精度说明

- 天体大小、轨道距离与奥尔特云半径经非线性压缩以兼顾可视性，界面已标注
- 日食/月食阴影大小经视觉放大以便观察
- 冥王星、谷神星轨道根数为近似值；月球相位未做精确对齐
- 银河系模型为形态示意，尺寸极度简化
